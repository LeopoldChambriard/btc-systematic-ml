# Archived coursework notebook

`coursework_2026-04_original.ipynb` is the original IMT Atlantique (FISE) coursework deliverable
(April 2026, *Systematic Trading Strategies with Machine Learning*), kept unchanged for
provenance, apart from the data URL, which was replaced by a placeholder. It still carries its
executed outputs.

**Do not cite its performance figures.** A later audit found look-ahead in the regime features and
several other problems that affect those numbers. They are listed, with the fix and a regression
test for each, in [`docs/leakage_audit.md`](../../docs/leakage_audit.md). The maintained,
corrected implementation is the `sysml` package in `src/`.

Original authors: Jofrey Husson, Yanis Bendaguir, Stanislas Robineau, Arthur Barbe,
Léopold Chambriard.
